06 — Questions

What clients ask before we start

01What does Bazozo build?

Bazozo Studio designs and builds custom websites and e-commerce stores, browser extensions for Chrome, Firefox and Safari (Manifest V3), WordPress plugins, iOS and Android apps, Windows and macOS utilities, mobile games, and brand films and motion graphics. Twelve disciplines, one team, so a launch site, its extension and its promo video can come from the same studio.

02Do you work with clients outside India?

Yes. The studio is based in India and works remotely with clients worldwide. We communicate in English, Hindi and Punjabi, by email, WhatsApp or video call, and plan check-ins around your time zone.

03How is a project priced?

Every project gets a written quote with a clear scope, milestones and timeline before any work starts. Payment is split into an advance and milestone payments, and anything outside the agreed scope is quoted separately first, so there are no surprise invoices.

04Are the portfolio projects real?

Baaz Records (baazrecords.in) is a live client site. Most other pieces are concept builds: working, interactive projects we designed and built to show what we can ship in each discipline. Every card opens a live demo you can use, and the brands inside concept builds are fictional.

05Will my website be fast, secure and SEO-ready?

Yes. We build with semantic HTML, structured data, image optimisation, lazy loading and a Content Security Policy, and we test on real phones. Technical SEO, Core Web Vitals and accessibility are part of every website project, not an add-on.

06Who owns the code and designs?

You do. Once the project is paid in full, the final designs, code and media made for you belong to you, as set out in our Terms of Service.

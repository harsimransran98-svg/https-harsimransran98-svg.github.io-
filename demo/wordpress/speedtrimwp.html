// architecture

settings
React admin screen built with @wordpress/components, saved through the REST API
assets
Minify and defer at build time, cached as static files with hashed names; one-click rollback
images
WebP and AVIF generated in the background with Action Scheduler; native lazy loading plus LCP preload
checkout
Hooks into woocommerce_checkout_fields and the Checkout block, with no template overrides
testing
PageSpeed Insights API runs on a schedule; score shown in the admin bar
safety
Every switch is reversible; capability checks and nonces on every save

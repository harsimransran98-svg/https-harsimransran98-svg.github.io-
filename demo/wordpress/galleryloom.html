theme

14 custom blocks (gallery, pricing, testimonial and more) built with @wordpress/scripts and block.json

        
patterns
Section patterns locked where they should be, editable where clients need them

        
responsive
Container queries per block, so sections adapt to their slot, not just the screen

        
speed
Blocks load their CSS and JS only on pages that use them; no jQuery, no page builder

// architecture

shell
Tauri 2: one Rust core, native windows on Windows, macOS and Linux
editor
CodeMirror 6 with live markdown decorations
storage
Plain .md files in a folder you choose, indexed with SQLite FTS5
graph
Links parsed incrementally, force layout on a WebGL canvas
sync
Optional end-to-end encrypted sync; works fully offline
safety
Markdown is rendered to DOM nodes, never raw HTML

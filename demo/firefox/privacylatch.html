// architecture

engine
declarativeNetRequest rules, so blocking happens inside the browser and no page data passes through the extension
browsers
One WebExtensions codebase for Firefox and Chrome; Safari via a Swift app extension wrapper
fingerprints
Canvas, audio and font probing get noise added instead of a hard block, so sites don't break
allowlist
Per-site pause synced with the browser's own storage, never a server
memory
Tracker scripts that never load are memory that's never used: measured per tab
privacy
Zero telemetry. The extension makes no network requests of its own

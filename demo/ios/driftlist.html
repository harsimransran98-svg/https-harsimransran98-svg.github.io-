Driftlist

Driftlist is built to be used without opening it. Tick tasks right on the home screen widget, and anything you keep putting off slowly drifts down the list so today stays honest.

  1. Tick a task in the widget
  2. Resize the widget
  3. Open the app
  4. Add a task and see it on the widget
  5. Check the Lock Screen

// architecture

shell
SwiftUI window with a native menu bar, Finder drag-and-drop and Quick Actions
codecs
ImageIO for JPEG, PNG and HEIC; libwebp and libavif bundled for WebP and AVIF
pipeline
Swift concurrency, one encoder per performance core, memory-capped
rename
Token patterns with live preview and collision-safe numbering
privacy
100% on-device. Location and camera metadata stripped by default
